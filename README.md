# LevelUp — Спортивный герой PWA

Мобильное PWA-приложение для детей: прокачивай героя через реальные тренировки, проходи карту спортивного города и сражайся с боссами.

## Возможности

- **Карта города** — перемещайся по маршруту, открывай новые локации по мере роста уровня
- **Тренировка с камерой** — приседания и отжимания с подсчётом повторений через MediaPipe (камера обрабатывается локально, видео не записывается)
- **Битвы** — пошаговые бои с противниками, навыки, критические удары
- **Система уровней** — XP за посещаемость, упражнения и победы
- **Оффлайн** — работает без интернета, синхронизация при подключении

## Стек

| Слой | Технологии |
|------|-----------|
| Фронтенд | React, Vite, Zustand, PWA (Workbox) |
| Бэкенд | Node.js, Express |
| БД | SQLite (better-sqlite3) |
| Pose detection | MediaPipe Tasks Vision (PoseLandmarker) |

## Структура

```
frontend-react/   — React-приложение (исходники)
server/            — API-сервер (Express + SQLite)
```

## Запуск (development)

```bash
# Фронтенд
cd frontend-react
npm install
npm run dev

# Бэкенд
cd server
cp ../.env.example .env   # заполнить JWT_SECRET
npm install
node index.js
```

## Сборка и деплой

```bash
cd frontend-react
npm run build              # результат в dist/
```
